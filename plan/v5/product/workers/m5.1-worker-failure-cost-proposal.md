## 1. Problem (Econ §0, §2, §3)
- In every breach cell, net(Asleep) − net(Working) = the wage exactly (W1 0.25·F $/min, W2 0.5·F $/min), because the player's own taps or check-ins already move every egg (Econ §3).
- Market Hand: every cell for idle / ac7 / optimal; Coop Hand: 219/264 cells (ac7), 245/264 (optimal) (Econ §2). Tired never out-earns (200-seed worst −$0.0005/s, Econ §2.2).
- No worker tunable fixes it (Econ §3). A rule is needed.

## 2. Rules (as ruled by HoP, D-HOP-2026-10-24-44 / -45)
- **FC-R1 Clock wage.** A hired Market Hand or Coop Hand that is **Asleep** (0%) is charged its wage at the same `w*_wage_per_min`, exactly as if Working: one `w*_every_s` interval wage each time its cooldown `cdS` expires. **Phase (U1, D-HOP-2026-10-29-02, §2a):** the worker keeps one wage/action cooldown `cdS` across Working, Tired and Asleep. No Working/Tired/Asleep transition writes `cdS`, and that includes falling asleep and being woken by a manual or auto Refill. The first Asleep charge lands on the step where the `cdS` carried in from Working/Tired reaches ≤ 0 (this may be the rest of a `w*_tired_every_s` interval). Each Asleep charge then sets `cdS` = `w*_every_s`. After a Refill, the first Working action and wage land on the step where the `cdS` left by the Asleep branch reaches ≤ 0; there is no fresh interval. `cdS` is set to 0 only on Unpaid entry (can't pay) and on auto-resume (U2). No new column (Econ §4).
- **FC-R2 Unchanged states.** Working/Tired: unchanged. **Paused** (M5.0 Pause, frozen): unchanged, no wage, **confirmed by D-HOP-2026-10-24-45** ("On break · no wage"); deliberately benching a worker is the accepted wage-skip (pause spec G-table "Accepted, not an exploit"). **Unpaid**: unchanged; auto-resume stays (D-HOP-2026-10-24-45: Pay wage closed). Unpaid can't be held by choice, so it is transient and harmless (Econ §2.3).
- **FC-R4 Can't pay while Asleep.** A clock-wage charge that coins can't cover follows the existing Unpaid trigger (`tick.ts:79-80`); mood precedence stays Unpaid > Asleep (rc1-asleep v1.0.10 (1)), so the card shows "Resumes at $X". **CONFIRMED by Econ** (shipping re-run §3.3). **Flip bound (D6, AC-FC15):** broke-trickle test (Econ §3.3 C; setup in AC-FC15) ≤ 12 Asleep↔Unpaid toggles per 30 min (measured 8–9); 200-seed neglect run (Econ §3.2, `CFG=neglect`; setup in AC-FC15) P95 0 and max ≤ 1 per 30 min (measured 0 / 0.6); managed runs 0. No wage is charged offline (Econ §3.3 B), so no offline rule is needed.
- **FC-R5 Offline.** No wage while offline/hidden ≥ `offline.offlineMinSeconds` (60 s), asleep or not (workers do nothing offline; pause spec E1). **CONFIRMED by Econ** (shipping re-run `reviews/m5.1-shipping-rerun-econ.c5870544.md` (frozen copy, sha1 c587054464081d3a19c32c0d38d3459a79ae1aa2, §0–9 identical in the current file `43ecbda1`, which only appends §10; section unchanged from frozen copy `reviews/m5.1-shipping-rerun-econ.41e65491.md`, sha1 41e654910cfef0e0bd15a3a30558f99deacf312c) §3.3 B, `h2/offtest.ts`): offline 10 min (`applyOffline`, 600 s, F20, clock on) leaves coins unchanged (123,456,789 → 123,456,789); `applyOffline` never calls `step()`, so neither wage branch runs, and a hidden gap ≥ 60 s reverts to the hide snapshot and settles through `applyOffline`. (The earlier caveat, that the h2 runs were tab-open only, is answered by this unit test.)
- **FC-R6 Hidden < `offline.offlineMinSeconds` (FC-G9, PM decision from existing rules).** The hidden-vs-offline threshold is 60 s: source of truth economy.csv `offline_min_s` (proposed row), runtime balance.json **`offline.offlineMinSeconds` / `hiddenSimMaxSeconds`** (see FC-R8). A hidden gap under 60 s is simulated live: rc2 v1.2 decision 1 ("use the existing frame-gap rule, so a gap of 60 s or more is treated as offline"), rc2 AC-RF2 ("a hide under 60 s is simulated normally"), pause spec E1 (exactly 60.0 counts as offline). So an Asleep MH/CH is charged the clock wage during a < 60 s hide exactly as in focus. At ≥ 60 s (60.0 included) the provisional sim is discarded and the whole gap is paid as offline (rv6 note: state reverts to the snapshot at hide), so the gap carries **no** wage.

## 3. Acceptance bar for the failure-cost design (Q-WF-1, HoP position D-HOP-2026-10-24-44)
"Asleep/Tired/Unpaid **≤** Working in every cell; **<** wherever the worker has non-redundant work." **Operational form (D4, FC-G7 CLOSED):** ≤ within τ everywhere, i.e. net(state) − net(Working) ≤ τ (ties |net(state) − net(Working)| ≤ τ pass); strict, Working − Asleep > τ, in non-redundant cells.
- **Gross marginal output (D4, Econ wording):** G(w, cell) = net(Working) − net(Asleep, clock wage on); the same wage is charged in both, so G is exactly the sales the Working worker adds. **Non-redundant cell:** G(w, cell) > **$0.05/s**.
- **Tie tolerance (D4):** τ = **$0.005/s** per cell, applied as |net(state) − net(Working)| ≤ τ. Evidence (200 seeds, Econ shipping re-run `reviews/m5.1-shipping-rerun-econ.c5870544.md` (frozen copy, sha1 c587054464081d3a19c32c0d38d3459a79ae1aa2, §0–9 identical in the current file `43ecbda1`, which only appends §10; section unchanged from frozen copy `reviews/m5.1-shipping-rerun-econ.41e65491.md`, sha1 41e654910cfef0e0bd15a3a30558f99deacf312c) §4): max redundant |G| $0.0024/s; min real G $0.367/s.
- **Carve-outs (D4):** Tired is held to ≤ net(Working) + τ, strict only where net(Working) − net(Tired) > τ. Unpaid is tested as a transient, not in the held map (AC-FC6 (c)).
- **Operative checks (HoQA R5-1, record-only):** the strict clauses are definitional. Asleep strict (Working − Asleep > τ) follows from the non-redundant definition (G = Working − Asleep > $0.05/s > τ), and Tired's strict clause applies only where its own condition (Working − Tired > τ) already holds. So the **≤ τ bars are the operative checks**; QA still runs both clauses as written.
- At F10+ the M5.0 calls give every Working worker a non-redundant bonus ≥ 8× the wage for players who use calls (Econ §3, MODEL), so strict < holds there for callers.
