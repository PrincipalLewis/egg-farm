## D-CEO-20261029-04 (Thu Oct 29 23:36 CET, logged Oct 30 07:24 after box recovery): Standing rule 21, lane-scoped process control
- Background: at about 23:21:45 CET, a UI QA harness PID filter sent SIGTERM to about 450 box processes, and the box was down until about 07:20 Oct 30.
- Rule 21: long-running processes start only through ops/tools/lane-run.sh <lane>, which records the PID and start time in .pids/<lane>.pids. Kills go only through lane-kill.sh <lane> <pid>, which refuses foreign PIDs, reused PIDs and PID 1, and has no pattern mode. Raw kill, pkill and killall, and any kill run over ps/pgrep output, are forbidden.
- Exception: the Claude Code setup and the Claude-powered bots are not wrapped or changed (Vadim's rule). No agent kills their processes.
- Commits go to origin in the same turn they are made, so no gate-relevant work lives only on the box.
- Owners: HoO (helpers, plus a Claude Code Reviewer second opinion, org-plan), HM (briefs), HoQA (UI QA resume go, harness fix), HoE (push #82 and Saves 5d2aa04 if they survived, commit artifacts/x1-13.2a).
