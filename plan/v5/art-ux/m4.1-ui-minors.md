### m8: `.cooptip` font, width and max-width (styles.css:186)
**Root cause.** `font:600 14px/1.3 inherit` is invalid: `inherit` can't be a value inside the shorthand, so the whole declaration is dropped. The tip then falls back to `button{font:inherit}` (styles.css:20), which inherits the body font: **Nunito 400 16px / line-height normal**. Because `left:50%` sits on a shrink-to-fit fixed box, the width is capped at 100vw − 50% (180px at 360, 195 at 390), so the tip wraps to 3 lines on phones.
**Font check.** `--f-body` = `"Nunito",system-ui,sans-serif`. Only Nunito 400 and 700 ship. At 14px the build tip's natural width is 400 = 320.91, **600 = 333.78, 700 = 333.78** (yawn tip: 322.66 / 336.98 / 336.98). So 600 already renders with the 700 face. Spec 700 to say what ships (Head 23:15).
