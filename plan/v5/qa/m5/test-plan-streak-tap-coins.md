- **I_ref:** Σ base-chain cents over the trailing 60 s of sim time / 6000, gross of wages. Hidden < 60 s sim sales count (spec v1.1 and D-HOP-07 agree). **Warm-up (§4.1a, D-HOP-10 #1, ST-2b closed):** `refWarmS` = 0 and the ring cleared on a fresh start / CSR reset, every page load (reload, new tab, takeover) and every offline return (hidden or frame gap ≥ 60.0 s). A hide < 60 s and menus don't restart it (the sim keeps ticking, so `refWarmS` also advances under the welcome-back modal). At F10, I_ss = $16.50/s, so a first tap after reload pays **50¢** (never 0¢).
- **Long frames (D-C3, HoE §13):** focusDt = min(frame dt, 1.0 s); sim ticks beyond the first 1.0 s of a long visible frame run with the streak (and Frenzy, calls) **suspended**, i.e. at (1 + 0).
