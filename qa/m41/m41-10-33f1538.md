**Where the build-id format is defined (quoted from scripts/build-id.ts @33f1538):**
> "export const BUILD_PREFIX = 'm4.1';" and "The build id is `<BUILD_PREFIX>+<short hash>[+dirty]`"

`+dirty` is added when `git status --porcelain` is non-empty, except for vite.config.*.timestamp-* files. vite.config.ts injects `__BUILD__` and `__BUILD_PREFIX__`. At runtime the id is exposed through `<meta name="build-id">`, `#app[data-build-id]` and telemetry session_start.build. There is deliberately no window global (src/main.ts, "F-META").
